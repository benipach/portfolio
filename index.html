Formula 1 Hub

Every Grand Prix in one place: the calendar in your local time, live timing, full results and championship standings, plus driver and team profiles and an archive covering the history of the sport.

View site Repository

Under the hood

  • Live timing: a Node.js relay connects to F1's official live timing feed (SignalR over WebSocket) and streams it to the site. It's deployed on Render.
  • A GitHub Actions job runs every 30 minutes on race weekends: when a session ends, it pulls results and weather from the OpenF1 API and commits the updated data.
  • A season archive, still a work in progress, that aims to cover the full history of F1: standings, cumulative points charts and career stats precomputed from every season.
  • JavaScript
  • Node.js
  • WebSockets
  • Chart.js
  • GitHub Actions
  • OpenF1 API

About me

Who I am and what I'm working on

My background, my skills and what I'm looking for.

I'm Benicio Pacheco, a developer from Buenos Aires. I'm finishing a six-year technical high school program in computing at Technical High School No. 35 “Ing. Eduardo Latzina”, focused on programming, databases and networking.

I work across the stack, and I enjoy designing an interface as much as working out the logic behind it. I code because I like building tools that are useful and well made: whenever an app could work better, I end up thinking about how I'd fix it.

I care about how things look, but just as much about logic that holds up in edge cases, because both shape the experience of the people using it. On top of what I learned at school, I taught myself web development, and that's how I built F1 Hub, my biggest project. The hardest part was keeping lap times and track positions in sync while live data streams in during a session.

Having worked on every layer, from the database to the server it runs on, helps me see how the pieces of a project fit together, and that makes teamwork easier. In my school internship, for example, my classmates and I set up an Ubuntu Server machine in the school's rack to host its website. In 2027 I start a Systems Engineering degree at UTN (National Technological University), so I'm looking for a part-time remote role where I can keep growing while I study.
